# 🎮 언리얼 1인칭 멀티 서바이벌 게임 기획서

> **장르**: 1인칭 멀티 서바이벌 / 정치 추리 / 탈출
> **엔진**: Unreal Engine
> **플레이 모드**: 개인전 / 듀오 / 트리오 (총 5팀 경쟁)
> **목표 매치 길이**: 20~40분 (3~4라운드 권장)

---

## 📌 1. 게임 개요

### 1.1 핵심 컨셉
플레이어는 미지의 장소에 갇힌 채, **낮에는 자원을 파밍**하고 **밤에는 무법지대 속에서 탈출구의 비밀번호를 찾아내야** 한다. 맵에 흩어진 여러 석상 중 **숫자가 적힌 3개의 석상**을 찾아 비밀번호를 조합하고, 다른 팀들을 견제하며 가장 먼저 탈출하는 것이 목표이다.

### 1.2 매치 구성
- **팀 수**: 총 **5팀**이 경쟁
- **모드별 인원**:
  - 개인전: 1인 × 5팀
  - 듀오전: 2인 × 5팀 (팀전 강제)
  - 트리오전: 3인 × 5팀 (팀전 강제)

### 1.3 승리 조건
**탈출구 1개**에 비밀번호를 입력하고 정원만큼 탈출한 팀이 승리한다.

| 모드 | 탈출 정원 |
|------|-----------|
| 개인전 | 2명 |
| 듀오전 | 2명 (팀 전체) |
| 트리오전 | 3명 (팀 전체) |

> ⚠️ **C안 룰**: 필요 정원 = 살아있는 팀원 수
> 팀원이 죽었다면, 살아있는 팀원만 탈출구에 도달하면 됨.
> 단, **살아있는 팀원 전원이 탈출구에 도달해야 비밀번호 입력 가능** (방식 2).

| 단계 | 내용 | 비고 |
|------|------|------|

## 🌗 3. 핵심 시스템

### 3.1 낮/밤 시스템

| 구분 | 특징 |
|------|------|
| **낮 (평화)** | 재료 파밍, 레시피로 아이템 제작, 자유 이동, **PvP 공격 불가** |
| **밤 (무법)** | 석상 탐색, **PvP 허용**, 견제전, 시체 약탈 가능 |

> 단, **도적의 강탈 능력은 낮/밤 모두 사용 가능** (하루 1회 제한, 자세한 내용은 §4 참조)

#### 라운드별 시간 변화 (제안안)

매 라운드 낮은 짧아지고 밤은 빠르게 길어진다. 대부분의 매치가 **3~4라운드 안에 종료**되도록 설계.

| 라운드 | 낮 | 밤 | 누적 시간 (점심 1분 포함) |
|--------|-----|-----|---------------------------|
| 1라운드 | 5분 | 2분 | 7분 |
| 2라운드 | 4분 | 3분 | 14분 |
| 3라운드 | 3분 | 4분 | 22분 |
| 4라운드 | 2분 | 5분 | 30분 |
| 5라운드 | 1분 | 6분 | 38분 |

> ⚠️ 위 수치는 **테스트 플레이 후 조정 필수**. 실제 플레이 데이터 기반으로 밸런스 확정.

### 3.2 점심시간 (대들보 시스템)
- 낮 중간에 **강제로 강당 집결** (1분간)
- 이 시간 동안 다음 활동 가능:
  - 재료 **물물교환** / **판매**
  - **레시피 판매**
  - 경매장 시스템 (예정)
- **"누군가가 무엇을 원합니다"** 식의 대들보(요청) 시스템으로 정치적 거래 유도
- 비밀번호 정보·석상 위치 정보의 거래 화폐화 가능 → 핵심 정치 콘텐츠

### 3.3 비밀번호 석상 시스템

#### 석상 배치
- 맵에 **20~30개**의 석상이 첫날 밤에 생성
- **위치는 한 매치 내내 고정**
- 그중 **단 3개의 석상**에만 숫자가 적혀 있음
- **숫자 위치(어떤 석상에)도 매치 내내 고정**
- **숫자 자체도 매치 내내 고정**

> 즉, 한 매치 안에서 비밀번호는 처음부터 끝까지 동일.
> "정찰 → 외우기 → 거래"의 가치가 극대화됨.

#### 비밀번호 입력
- 3자리 숫자를 **올바른 순서**로 입력해야 함 (3! = 6가지 경우의 수)
- 순서를 틀릴 경우 **해당 팀에 30초 락** 걸림
- 락 동안 같은 팀은 비밀번호 재입력 불가

#### 입력 조건 (방식 2)
- 살아있는 팀원 **전원이 탈출구에 도달**해야 입력 가능
- → 막판 팀 집결 클라이맥스 자연 발생

### 3.4 탈출구
- **탈출구는 1개** (모든 모드 공통)
- 모든 팀의 병목 지점이 됨 → 막판 PvP 집중
- 방호벽·함정 등 큰 인벤토리 아이템의 가치 폭증

### 3.5 레드 플레이어 시스템
- 다른 플레이어를 **살해한 자**는 **다음 라운드 밤까지 레드 플레이어**가 됨
- 모든 플레이어의 맵에 **레드 플레이어의 위치가 표시**됨 → 표적이 됨
- 시체 약탈로 인한 살인 보상은 크지만, 위치 노출이라는 명확한 페널티

### 3.6 시체 약탈 시스템
- 죽은 플레이어의 인벤토리는 **시체에 그대로 남음** (배틀그라운드식)
- 누구나 약탈 가능 → 살인자 외 제3자도 이득 가능
- *"살인 → 시체 → 다른 팀이 시체 약탈"* 의 새로운 전투 트리거 발생

### 3.7 부활 시스템
- **없음**
- 매치 시간 압축 + 살인의 무게 유지를 위해 의도적으로 배제

## 👥 4. 직업 시스템 (5종)

### 4.1 🪖 군인
- **파밍 속도** 다른 직업 대비 **1.3~1.5배** 빠름
- **전투 보너스** (예: 무기류 공격력 +20%, 또는 시작 시 단검 1개 지급) — 세부 수치 추후 결정
- 컨셉: 전투·파밍 균형형

### 4.2 💊 약사
- **전용 회복 레시피** 보유 (직업 고유)
- 체력 회복 아이템 제작 가능
- 컨셉: 팀 생존 지원형

### 4.3 🗡️ 도적
- **하루 1회**, 상대 플레이어의 **재료 또는 아이템 1개**를 랜덤 강탈 가능
- 발동 조건:
  - **상대의 등 뒤 근접** (1~2m 이내)
  - **시전 시간 1.5초** (도중 들키면 실패)
  - **낮/밤 모두 사용 가능**
- **레시피는 강탈 불가** (게임 흐름 자산은 보호)
- 컨셉: 잠입 정치형

### 4.4 🏃 마라토너
- 달릴 때 **기력 소모 50% 감소**
- 컨셉: 정찰·도주 특화

### 4.5 ✏️ 만화가 (시그니처 직업)
- **하루 1회**, 비밀번호가 적혀있지 **않은** 석상에 **임의의 가짜 숫자**를 입력 가능
- 가짜 숫자는 진짜 숫자와 **시각적으로 구분 불가**
- **다음 낮 시작 시 소멸** (하룻밤 동안만 유효)
- 컨셉: 정보 교란·심리전형

## 🎒 5. 플레이어 스탯 & 인벤토리

### 5.1 인벤토리 시스템

#### 기본 구조
- **개인당 배낭 10칸** 고정
- **칸 수 차등 시스템**: 아이템마다 차지하는 칸 수가 다름
  - **슬롯 합산 방식** (Tetris식 그리드 아님)
  - 예: 방호벽 4칸 + 칼 3칸 + 포션 1칸 × 3 = 10칸 풀

#### 칸 수 가이드라인 (예시)

| 칸 수 | 분류 |
|-------|------|
| 1칸 | 소비 아이템 (포션, 음식, 작은 재료) |
| 2칸 | 단검, 도구류 |
| 3칸 | 칼, 중간 무기 |
| 4칸 이상 | 방호벽, 함정, 대형 장비 |

#### 라운드 종료 시
- **제작 아이템 → 소멸**
- **재료 → 유지**

### 5.2 기력 (MP) 시스템

플레이어의 모든 행동은 **기력**을 소모한다.

| 행동 | 기력 변화 |
|------|-----------|
| **공격** | -10 ~ -20 (행동마다 다름) |
| **달리기** | 초당 -5 (마라토너는 -2.5) |
| **걷기** | 회복 (약 10초면 풀 충전) |
| **공격 직후** | 회복 정지 (쿨다운 존재) |

> 기력이 낮을수록 **헉헉거리며 이동속도 감소** → 긴장감 연출

## 🎨 9. 디자인 방향성

- **긴장감**: 낮의 평화로움 ↔ 밤의 무법 대비

- **시간 압축**: 20~40분 매치, 3~4라운드 권장

## 📌 11. 결정 이력 (v1.0 → v1.1 변경사항)

### v1.0 → v1.1 주요 변경
1. **석상 시스템**: 매 라운드 랜덤 → **위치·숫자 모두 매치 내 고정**
2. **탈출구**: 모드별 2~3개 → **모든 모드 1개로 통일**
3. **탈출 룰 신설**: C안 (살아있는 팀원 수 = 정원) + 방식 2 (전원 도달 필요)
4. **비밀번호 입력 실패 페널티 신설**: 팀 30초 락
5. **직업 능력 구체화 및 밸런스 조정**:
   - 군인 파밍 2배 → 1.3~1.5배 + 전투 보너스
   - 도적: 등 뒤 근접 + 1.5초 시전, 레시피 강탈 불가, 낮/밤 모두 사용 가능
   - 만화가 가짜 숫자: 다음 낮 시작 시 소멸 명시
